# 🐾 WildVision AI – Animal Image Classification Using CNN

## 📌 Project Overview

**WildVision AI** is a deep learning-based animal image classification project developed using Python, TensorFlow, and Convolutional Neural Networks (CNN).

The main objective of this project is to develop an intelligent system that can recognize and classify different animal images automatically using deep learning techniques.

The model is trained using the **Animals-10 dataset from Kaggle**, which contains images belonging to 10 different animal categories. It uses image preprocessing, data augmentation, CNN architecture, and model evaluation to achieve accurate animal classification.

Users can provide their own animal images, and the trained model predicts the animal category along with its confidence score.

## 🎯 Project Objectives

- Develop an AI-based animal image classification system.
- Classify images into 10 different animal categories.
- Apply CNN for image feature extraction and classification.
- Perform image preprocessing and data augmentation.
- Train and evaluate a deep learning model.
- Predict animal categories from user-provided images.
- Visualize model accuracy, loss, and confusion matrix.

## 📂 Dataset Information

The dataset contains 10 animal categories:

2. Cat

4. Elephant

7. Cow
